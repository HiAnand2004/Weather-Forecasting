# 🌦️ Weather Forecast Web App

A simple and interactive weather forecast application built using **HTML**, **CSS**, **JavaScript**, and **PHP**. This app allows users to search for a city and view current weather data such as temperature, humidity, wind speed, and weather conditions using a weather API (like OpenWeatherMap).

---

## 🖼️ Features

- Search weather by city name
- Displays:
  - Temperature
  - Weather conditions (e.g., Clear, Rainy)
  - Humidity
  - Wind speed
  - Weather icons
- Fully responsive web UI
- Real-time weather data using API

---

## 🔧 Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP
- **Weather API**: [OpenWeatherMap](https://openweathermap.org/api) (or similar)
